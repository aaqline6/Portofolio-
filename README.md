# Aaqilah Adelline Syndri — Portfolio 2026

Personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS using the **Tactile Editorial Bento** layout.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this repository to GitHub (branch `main`).
2. Import the repository in [Vercel](https://vercel.com/new).
3. Vercel automatically uses `vercel.json` (`framework: vite`, `buildCommand: npm run build`, `outputDirectory: dist`).
4. Click **Deploy**.
